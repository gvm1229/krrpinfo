## 검증

- Windows·Codex: TypeScript 검사·관련 테스트 28개·프로덕션 빌드 실제 통과. 운영자·공개 조회·업로드 확인은 실제 함수와 모의 서비스로 검증, 실제 외부 연결은 별도
- 로컬 Docker PostgreSQL 17: 초기 SQL 적용·재실행 확인, 비로그인 역할의 직접 테이블 조회 거부 확인
- 로컬 PostgREST·Next.js 브라우저: 자체 로그인·Draft 저장·공개 주소 404·Published 저장 후 본문/표/접기/사이트맵 반영 확인
- 같은 브라우저에서 메뉴와 페이지 숨김/복원, 밝은/어두운 화면, 390px 공개/관리 배치, Markdown 한글 입력·공통 미리보기·저장 확인
- Blocks 붙여넣기·실행 취소·다시 실행과 Markdown 저장 후 재열기, 로그아웃 후 로그인 화면 이동 확인. 두 편집기의 접근성 이름 지정
- 관리자 날짜를 한국 시간으로 표시, 본문 형식 변경 시 초기화 확인, 잘못된 편집 식별자는 404 처리, CodeMirror 접근성 이름 지정
- 디자인 검사에서 현재 관리자 색상·글자 크기 문서 누락을 보완. Prettier 지원 형식은 정리했으며 SQL은 해당 포맷터에 파서가 없어 제외
- Windows 이전 사전 점검: 실제 원본 글 2개·영상 33개·연결 이미지 31개, 누락 이미지 없음, 원본 DB 변경 없음
- Linux Docker Node 24: 이전 도구 시작·사전 점검·입력 누락 시 실패 종료 확인, 이미지 검사는 별도 마운트 없이 수행하여 대상 이미지 미검증
- 실제 R2의 임시 PNG 전송·서명 PUT·정보 확인·공개 파일 바이트 일치·삭제 통과. Windows·Codex에서 실행했고 관리자 업로드 완료 등록은 DB·로그인 초기화 후 확인 필요
- R2 CORS는 localhost:3000의 사전 요청 403, 정책 조회 AccessDenied로 사용자 Dashboard 설정 필요. 기존 정책은 변경하지 않음
- Supabase API는 응답하나 CMS 테이블 조회는 PGRST205. DATABASE_URL·AUTH_SECRET·AUTH_OWNER_ID·AUTH_PASSWORD_HASH 누락으로 초기 SQL·실제 이전·로그인 검증 대기
- Vercel Preview·물리적 한국어 IME 조합은 미검증
- GitHub CI는 Windows/Linux Node 24 검사로 갱신했으나 push를 실행하지 않아 실제 CI 실행은 미검증
- Hive 0.13.0 설치 기록 한 파일을 project-refresh로 보완한 뒤 설치 validate 통과, 사용량 30% 보존. 프로젝트 전용 공개 저장 규칙의 지식 기록·파생 색인 확인과 lint 통과
- 최종 0.1.22의 frozen-lockfile 설치·테스트 28개·타입·빌드 통과. 단계별 index 검사에는 같은 설치 패키지를 사용했으며 별도 host별 설치 검증은 아님
- Strapi LICENSE 원본 공백 보존. 시험용 기동 설정은 127.0.0.1과 로컬 DB에 한정하고 실제 R2·Nexon 값 상속 차단, 타입 확인. 이 설정으로 브라우저 재기동은 미실행

- SUPABASE_URL의 Data API 역할과 DATABASE_URL의 초기 SQL 접속 역할, 공식 Session pooler 안내 기록
- 사용자 요청으로 AUTH_SECRET 난수 생성·로컬 저장, 비밀값 미출력·다른 설정 보존·Git 제외 확인. 제품 코드와 버전 변경 없음
- Windows·Codex 후속 확인: AUTH_OWNER_ID 등록, AUTH_SECRET 로딩, CORS 사전 요청 HTTP 204와 localhost 허용 확인. DATABASE_URL 누락·AUTH_PASSWORD_HASH 형식 불일치로 실제 로그인과 SQL 적용은 미검증

## 📝 docs — 환경변수 읽기 전용 검증

- Windows·Codex에서 필수값 12개·해시 형식·프로젝트 일치·Next.js 설정 로딩 확인
- 실제 R2 버킷 조회 200, 앱 출처의 CORS 사전 요청 204·PUT 허용 확인
- DB 직접 연결 주소에 IPv6 DNS만 있고 호스트에는 IPv6 기본 경로가 없어 ENOENT 발생. 비밀번호 인증·DB 변경·로그인은 미검증, Session pooler 주소로 교체 필요
- 환경변수와 실제 DB 데이터는 변경하지 않음. 문서만 갱신하여 제품 버전·제품 시험 변경 없음
