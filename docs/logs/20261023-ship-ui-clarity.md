# 2026-10-23 — UI 개선 커밋과 후속 사용성 정리

> version: 0.1.26 · feat/cms-mvp

## 🎨 style — 후속 UI 정리 (0.1.27)

- 앞선 제목 배치와 관리자 저장 흐름 유지. 홈 글자 크기를 14·16·24·30px로 정리하고 글과 영상 카드 제목을 16px로 통일
- Radix Gray의 역할별 밝은·어두운 값을 공통 토큰에 적용. 기존 파랑과 관리자 보라색 유지, 브랜드 버튼 hover 대비와 관리자 입력 경계 강화
- 일정 카드 모서리를 8px로 정리하고 태그를 중립색으로 구분. 검색창의 겹친 모서리 제거
- 관리자 최근 목록의 장식 구분점 제거, 모바일에서 제목과 상태를 별도 줄로 표시. 설정 제목을 자연스러운 연결어로 변경
- 일반 버튼과 관리자 메뉴에 250ms ease-out 적용, 움직임 줄이기 설정 대응

## 🐛 fix — 키보드와 상태 표시

- 테마 버튼 초점 표시 복원, 선택 항목을 라디오 메뉴로 제공, 불필요한 아이콘 회전 제거
- 태그 버튼 중첩 제거, 접근 가능한 이름과 펼침 상태 추가. 펼친 상태에서 너비가 바뀌어도 접기 버튼 유지
- 검색 입력 이름과 닫기 후 버튼 초점 복귀 추가
- 자체 로그인 입력과 버튼을 shadcn으로 연결. 진행 상태와 실패 안내 유지, 두 테마의 오류 색을 Radix Red 11로 구분

## 후속 검증 범위

- Codex·Windows·Chrome에서 분리된 로컬 PostgreSQL/PostgREST와 기존 이전 자료로 실행. 홈·글 목록·영상 목록·관리자 대시보드·글 관리·설정의 390/768/1440px와 두 테마 조합 36회에서 페이지 가로 넘침 없음. 일반 화면 글자 크기 3~4개, 보조 글씨 최소 12px 확인
- 키보드 테마 선택, 태그 펼침/접기와 너비 변경, 검색 빈 결과와 Escape 초점 복귀, 관리자 빈 검색, 로그인 진행/비활성/실패 상태 확인
- 최종 변경 기준 Vitest 32개, TypeScript, 프로덕션 빌드 통과. 정상 로그인과 모바일 메뉴 키보드 조작 확인. 움직임 줄이기는 CSS 분기만 확인했으며 운영체제 설정을 전환한 검사는 미실행
- 계산한 대표 대비: 보조 글씨 5.19:1 이상, 브랜드 버튼 5.17:1, hover 6.70:1, 관리자 입력 경계 밝음 3.22:1/어두움 5.00:1. 모든 콘텐츠의 색 대비나 스크린 리더 사용 전체를 증명하는 결과는 아님
- 수정 전후 캡처와 측정은 로컬 `.hive/runtime/ui-refinement/`에 보관. 사용자 원문과 운영 데이터 수정 없음
- Impeccable 변경 UI 정적 검사 지적 0개. taste 정적 검사의 1px 경계 지적은 화면 구분과 기존 디자인 보존을 위한 예외. 기존 미사용 gradient 문자열은 실제 배경을 만들지 않으며 요청 밖의 기존 불용 속성이므로 유지
- 실제 모바일 기기, Safari/Firefox, 스크린 리더, Linux CI, 운영 Supabase/R2와 배포는 미실행. Windows 로컬 결과만 확인했으며 외부 환경의 성공을 뜻하지 않음
- 임시 개발 서버와 이번 작업에서 만든 Docker DB/REST 컨테이너 정리. UI 원칙은 기존 user-root 지식과 같아 no-op, 정본과 파생 색인 검사 통과
