## 💄 style

- 글·영상 제목은 줄바꿈하고 요약은 두 줄까지 표시. 날짜·태그를 뒤에 배치하고 빈 태그 영역·같은 제목을 반복하는 접근성 이름 정리
- 공개 화면 제목과 콘텐츠의 왼쪽 기준선 통일. 홈 일정에서 제목과 완전히 같은 설명만 표시 생략, CMS 원문·순서·노출 보존
- 영상 분류를 기존 shadcn Tabs로 연결. 분류·첫 선택값·외부 영상 주소 유지
- 공개·관리자 메뉴의 현재 위치 표시, 작은 화면의 메뉴와 표만 해당 영역 안에서 가로 이동
- 쿠폰 입력·저장·제출과 도움말을 구분하고 번호 찾는 설명의 크기 축소. 필수 안내·오류·기존 저장/수정/취소 유지
- 관리자 목록의 현재 상태와 상태 변경 동작 분리. 대상 이름이 포함된 추가 버튼, 편집·삭제 글자, 검색 결과 없음과 최초 빈 목록 구분
- 편집 화면의 공개 상태·저장·오류를 상단 고정. 작성 내용과 주소·날짜·태그·검색 키워드·표시 순서 분리
- 사이트 설정을 페이지 표시·기본 정보·홈·연락처/푸터·쿠폰 안내·검색/사이트 확인으로 묶음. 기존 모든 설정 필드와 저장 형식 유지
- 미디어 선택·업로드의 동작 이름과 묶음 정리. 수정한 자체 조작 UI에 shadcn 적용, Textarea·AlertDialog만 기존 의존성으로 추가
- Strapi 원본·Slate·CodeMirror 내부와 기존 색상·글꼴·이미지·API·인증·데이터 구조 보존

## 제외·미검증

- 사용자가 제외한 쿠폰 실제 사용 연결은 수정하지 않음. 기존 ‘회원 번호 제출’은 값을 기록할 뿐 실제 요청으로 연결되지 않는 상태
- 실제 R2 업로드·삭제는 분리된 시험 환경에 외부 자격 증명을 넣지 않아 실행하지 않음. UI 선택·취소·대체 설명 저장과 기존 권한 테스트 범위만 확인
- 실제 휴대전화·스크린 리더·Linux 실행·배포는 이번 Windows 로컬 검증으로 증명하지 않음
- 새 패키지 설치·원격 push·배포·커밋은 수행하지 않음
