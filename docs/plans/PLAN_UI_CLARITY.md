# 배치로 사용법을 드러내는 UI 개선

> 2026-10-22 · 사용자 계획 승인 · feat/cms-mvp

## 목표와 범위

- 공개 화면과 관리자 화면을 같은 비중으로 개선. 기존 색상·글꼴·게임 이미지·CMS 원문·주소·권한·저장 구조 보존
- 공개 화면: 원하는 콘텐츠 찾기, 일정 확인, 회원 번호 입력·저장과 쿠폰 확인
- 관리자: 콘텐츠 검색·작성·저장, 사이트 설정 수정, 이미지 선택
- 실제 쿠폰 사용 연결 복구와 배포는 제외. 현재 회원 번호 제출은 실제 요청으로 연결되지 않는 기존 문제

## 확인한 문제

- 390px 모바일 영상 화면에서 문서 너비 990px, 카드 너비 약 958px로 가로 넘침
- 공통 카드 제목 한 줄 잘림, 일정 제목·설명 중복, 섹션 제목과 콘텐츠 기준선 불일치
- 시즌 카드의 고정 너비와 날짜 표시점이 작은 화면에 부적합
- 쿠폰 입력·저장·제출과 큰 도움말의 시각적 우선순위 불분명
- 관리자 현재 상태와 변경 버튼 혼합, 모바일 저장 영역이 본문 뒤에 위치
- 설정 필드의 긴 나열, 미디어 선택 동작과 대화상자 접근성 이름 불분명

## 구현 순서

1. 공개 카드·목록의 너비와 제목 계층, 홈 중복 표시·정렬, 영상 Tabs, 시즌 크기·표시점 정렬, 쿠폰 입력과 도움말 구분
2. 공개·관리자 현재 메뉴 표시와 자체 조작 요소의 shadcn 사용
3. 관리자 목록의 상태·행동 구분, 대상이 명확한 버튼, 빈 목록과 검색 결과 없음 구분, 삭제 확인창
4. 편집 상단 상태·저장·오류 영역 고정, 본문과 부가 정보 분리, 본문 형식 변경 확인창 보존
5. 설정을 페이지 표시·기본 정보·홈·연락처/푸터·검색/사이트 확인으로 묶기. 미디어 Dialog·명확한 선택/업로드·초점 처리
6. 기존 의존성으로 Textarea·AlertDialog 보완. Strapi 원본·Slate·CodeMirror 내부 보존
7. 검사·화면 비교 후 patch 버전 1회 증가, 일일 기록·PR.md·필요한 USER_TASKS.md 갱신

## 검증 기준

- Codex·Windows·Chrome에서 390/768/1440px, 밝은/어두운 테마. 문서 전체 가로 넘침·제목 잘림·버튼 줄바꿈·고정 작업 영역의 가림 확인
- 공개 메뉴·검색·영상 분류/방향키·쿠폰 입력 오류/저장/수정/취소, 관리자 검색/필터/페이지·저장/실패·미디어 선택/취소 확인
- 상태 변경·저장·미디어 작업은 분리된 시험 데이터에서만 실행. 실제 쿠폰 요청 제외
- 변경 파일 Prettier, TypeScript, 기존 Vitest, 빌드. 단순 여백/문구와 구현을 그대로 복제한 테스트는 추가하지 않음
- 같은 화면·크기·테마의 전후 이미지 보존. 실제 기기·스크린 리더·외부 저장소 업로드 등 미검증 범위 분리
